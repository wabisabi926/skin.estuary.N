✨ 界面样式统一优化
- 全局材质统一：设置页全面适配首页高级毛玻璃材质，统一主菜单卡片、左侧边栏及 PVR、媒体、插件等全部侧边栏样式；设置页背景跟随首页背景图，无媒体浏览场景保持纯黑底色
- 卡片样式升级：用户配置档案卡片由纯黑实底改为半透明玻璃效果，与文件管理器等窗口视觉风格保持一致
- 弹窗控件统一美化：播放控制条、快进、书签、滑块、通知、倍速、播放信息、字幕下载、OSD 设置、播放列表、右键上下文菜单等所有弹窗面板，统一采用半透明黑色圆角样式；同步适配公共信息对话框，全局视觉规整统一
- 键盘样式优化：搜索键盘字母键统一改为小写样式，同步统一键盘侧栏背景配色

🎨 聚焦交互优化
- 全局聚焦样式标准化：统一聚焦高亮效果为 25% 透明白色圆角样式，长条类控件聚焦固定 12px 圆角
- 文字对比度修复：列表、按钮聚焦状态文字统一改为白色，彻底解决浅色底色下黑白文字显示不清、可读性差的问题；特殊适配视频信息页「播放」按钮，因底色过亮单独调整为深色聚焦文字
- 
🛠️ 细节体验修复
- 界面重叠优化：修复首页时钟与加载进度圆环重叠问题，重叠时自动隐藏时钟，避免视觉遮挡
- 排版对齐优化：媒体处理窗口内，内存占用、播放器缓存数值统一左对齐，界面排版更规整整洁
